Практична робота № 2 — ФІНАЛЬНА ВЕРСІЯ

1. Розмістіть три файли index.html, sw.js, manifest.webmanifest у корені репозиторію GitHub Pages.
2. У Settings > Pages оберіть Deploy from a branch, гілку main, папку /(root).
3. Відкрийте HTTPS-посилання на смартфоні при наявності Інтернету та дочекайтеся повідомлення «Офлайн підготовлено».
4. Для перевірки офлайн-режиму вимкніть Інтернет і повторно відкрийте сторінку.
5. Одне проходження обмежене локальними даними браузера; очищення даних або інший браузер обходять це обмеження.
6. Зміни прогресу зберігаються лише у браузері учня; без серверної бази вчитель не отримує результати автоматично.
7. Перед уроком протестуйте на окремому пристрої і оберіть правильне посилання.
8. Не публікуйте тестовий файл: користуйтеся лише цими фінальними файлами.
